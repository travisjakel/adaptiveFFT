# Names of the 14 FFTrees benchmark datasets

These are the classification datasets bundled with the FFTrees package
(Phillips, Neth, Woike & Gaissmaier, 2017), minus pre-split variants of
\`heartdisease\` (\`heart.train\`, \`heart.test\`, \`heart.cost\`).

## Usage

``` r
FFT_DATASETS
```

## Format

An object of class `character` of length 14.
