# Mean cues used per prediction (frugality)

Mean cues used per prediction (frugality)

## Usage

``` r
m_frugality(n_cues_per_row)
```

## Arguments

- n_cues_per_row:

  Integer vector — depth at which each test case exited the tree.

## Value

Scalar mean cues per row, or \`NA\` if input is \`NULL\`.
